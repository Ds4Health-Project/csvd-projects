# Instalar dependências

No diretório `project2`, execute:

```bash
python3 -m pip install -r requirements.txt
```

## Funções dos códigos da pasta `src`

- `io_transforms.py`: leitura, transformação e salvamento de dados.
- `metrics.py`: cálculo de `Log2FC` e filtro de genes significativos.

## Formatação

O código foi formatado com `black`.
